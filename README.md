# RBLX Market 2.0

Полноценный учебный full-stack прототип: Node.js + Express + SQLite.

## Что есть
- регистрация и вход;
- bcrypt-хэши паролей + JWT;
- профили и настройки;
- маркет: создание товара, покупка и тестовый баланс;
- трейды;
- личные сообщения;
- тикеты поддержки;
- админ-панель: пользователи, блокировка, поддержка, журнал действий;
- адаптивный интерфейс.

## Запуск
1. Установи Node.js 18+.
2. Скопируй `.env.example` в `.env`.
3. В `.env` укажи `ADMIN_EMAIL` — email, который должен получить роль ADMIN при регистрации.
4. Выполни `npm install`.
5. Выполни `npm start`.
6. Открой `http://localhost:3000`.

SQLite-файл `market.db` создаётся автоматически.

## Важно
Баланс — тестовая внутренняя валюта, не реальные деньги. Для настоящих платежей нужны отдельный платёжный провайдер, юридические условия, защита от мошенничества и модерация. Для несовершеннолетнего пользователя любые реальные платежи/договоры должен оформлять родитель или опекун.
